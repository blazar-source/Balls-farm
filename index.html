Мобильная игра «Ферма шариков» для Android

Дата публикации: 07 мая 2026 года
Разработчик и оператор приложения: индивидуальный предприниматель Бугров Геннадий Дмитрович
Контакт для вопросов по конфиденциальности и поддержке: blazargames@ya.ru

1. Общая информация

«Ферма шариков» - казуальная головоломка. Приложение не требует регистрации, не просит указать имя, телефон, адрес электронной почты или другие контактные данные пользователя.

2. Какие данные обрабатываются локально

Приложение может сохранять на устройстве:

  • прогресс уровней;
  • количество звезд и игровой валюты;
  • инвентарь игровых помощников;
  • настройки музыки, звуков и вибрации;
  • лучшие результаты уровней.

Эти данные используются только для работы игры и сохранения прогресса. Они хранятся локально на устройстве пользователя.

3. Какие данные приложение не собирает

Приложение не запрашивает и не собирает:

  • геолокацию;
  • контакты;
  • фотографии и видео пользователя;
  • доступ к камере;
  • доступ к микрофону;
  • SMS и историю звонков;
  • платежные данные;
  • данные учетных записей;
  • пользовательский контент или сообщения.

4. Разрешения приложения

Приложение использует следующие разрешения Android:

  • доступ к интернету и состоянию сети - для технической работы подключенных SDK и возможных сетевых функций;
  • вибрация - для игрового виброотклика.

Приложение не использует разрешения геолокации, камеры, микрофона или контактов.

5. Реклама и сторонние SDK

В приложение интегрирован Yandex Mobile Ads SDK.

Для рекламного SDK в приложении установлены privacy-настройки:

  • персонализированное согласие пользователя не передается как подтвержденное;
  • приложение помечено как предназначенное для возрастно ограниченной/детской аудитории;
  • отслеживание местоположения отключено.

Рекламный SDK может обрабатывать технические данные, необходимые для показа рекламы, предотвращения нарушений, измерения показов и кликов, в соответствии с правилами и политиками соответствующего SDK.

6. Аналитика

В текущей реализации игровые события используются локально для отладки и не отправляются на внешний сервер разработчика. В debug-сборках события могут выводиться в системный журнал устройства для тестирования.

7. Передача данных третьим лицам

Разработчик не продает персональные данные пользователей и не передает их третьим лицам для самостоятельного использования.

Техническая обработка данных может выполняться сторонними SDK, если такие SDK активны в приложении и необходимы для рекламы, диагностики или работы магазина приложений.

8. Дети

Игра рассчитана на широкую аудиторию, включая детей. В приложении нет пользовательского общения, публикации пользовательского контента, ссылок на социальные сети внутри игрового процесса и запроса личных данных ребенка.

9. Хранение и удаление данных

Локальные игровые данные хранятся на устройстве. Пользователь может удалить эти данные, удалив приложение или очистив данные приложения средствами Android.

10. Изменения политики

Политика может обновляться при изменении функциональности приложения, подключении новых SDK, рекламы, платежей или требований магазина приложений. Актуальная версия политики доступна по ссылке, указанной на странице приложения.
